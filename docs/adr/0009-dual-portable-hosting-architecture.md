# Dual Portable Hosting Behind Cloudflare DNS

The application is designed to run identically across two deployment targets—a self-hosted **Arch Linux** server (`Docker Compose` + local PostgreSQL + local SSD storage + `Cloudflare Tunnel`) and a cloud container fallback (**Render / Railway / Koyeb** running the exact same Docker image + **Supabase PostgreSQL & Storage**)—controlled strictly through environment variables (`DATABASE_URL`, `STORAGE_DRIVER=local|supabase`) without code changes. All printed QR codes point to a custom domain managed in **Cloudflare DNS**, decoupling physical signage from the active server so traffic can be routed to either Arch Linux or the cloud in seconds. To preserve portability, application code must access persistence exclusively through standard PostgreSQL queries/ORM and a server-side `PhotoStorage` interface, never coupling UI components directly to vendor-specific client SDKs.
