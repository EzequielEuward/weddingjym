# Modular Hub Navigation and Incremental Section Scope

The application uses a "Hub / Bento" home screen featuring a compact live preview of recent photos alongside dedicated entry cards for each functional module, backed by real URL routes (e.g., `/galeria`, `/best-outfit`) rather than in-memory view state. Using real URL routes preserves native mobile browser "Back" button and swipe-back gestures, while keeping a compact preview on the home screen prevents an infinite photo stream from burying secondary sections down the page. Each section handles its own contextual photo uploads directly (batch uploads in General Gallery; single-photo entries in Contests) without requiring category dropdowns. For initial MVP delivery, scope focuses on two active modules (**General Gallery** and **Best Outfit**), while each module card supports a simple configuration status (`active | coming_soon | hidden`) so **Best Bloopers** and **Wedding Bingo** (envisioned as a randomized musical card game) can remain parked as *"Próximamente"* (or hidden on event day if unused) without complicating the initial build.
